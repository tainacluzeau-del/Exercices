➕ Comment ajouter un nouvel exercice (pour toi)

1. Dépose le nouveau fichier HTML de l'exercice dans le même dossier GitHub que cette page (ex. roue-des-verbes.html).
2. Ouvre ce fichier index.html, repère le tableau EXERCICES en bas du code source, et ajoute un nouvel objet sur le modèle ci-dessous (copie-colle, puis modifie les valeurs).
3. Enregistre et republie (commit + push) — la carte apparaît automatiquement, avec son filtre d'unité. 

{
  titre: "Nom de l'exercice",
  emoji: "🎲",
  description: "Une phrase courte qui explique l'exercice.",
  fichier: "nom-du-fichier.html",
  unite: "Unité 2",
  type: "Jeu de grammaire"   // ou "CO", "CE", "PO", "PE"...
}
D'autres exercices seront ajoutés au fur et à mesure.
